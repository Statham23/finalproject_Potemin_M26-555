# ValutaTrade Hub

Консольное приложение на Python для симуляции торговли
фиатными валютами и криптовалютами.

## Возможности

На текущем этапе реализованы:

- Регистрация и авторизация пользователей.
- Управление виртуальными валютными кошельками.
- Покупка и продажа валют в рамках учебной модели.
- Просмотр балансов и стоимости портфеля.
- Получение валютных курсов с кешированием и использованием заглушки Parser Service.
- Обработка ошибок с помощью пользовательских исключений.

Планируется реализовать:

- Логирование операций покупки и продажи.
- Подключение внешнего источника валютных курсов.
- Принудительное обновление курсов через `update-rates`.

## Модель торговли

В проекте используется упрощённая модель симуляции торговли валютами.

- При покупке (`buy`) баланс выбранной валюты увеличивается без списания средств с USD-кошелька.
- При продаже (`sell`) баланс выбранной валюты уменьшается, а оценочная выручка рассчитывается в USD без фактического зачисления средств.
- Начальный виртуальный баланс пользователям не начисляется.
- USD используется как базовая валюта для расчёта стоимости портфеля. При необходимости стоимость может отображаться в другой поддерживаемой валюте.
- Для расчётов используются сохранённые валютные курсы или демонстрационные значения, полученные от заглушки Parser Service. В дальнейшем предусмотрено подключение реального источника курсов.

## Команды CLI

Приложение предоставляет консольный интерфейс для управления пользователями, валютными портфелями и получения курсов валют.

### 1. register

**Назначение:** регистрация нового пользователя.

**Синтаксис:**
register --username <username> --password <password>

**Пример:**
`register --username alice --password password123`

**Ошибки:**
- Пользователь с указанным именем уже существует.
- Имя пользователя или пароль не соответствуют требованиям.

### 2. login

**Назначение:** авторизация зарегистрированного пользователя.

**Синтаксис:**
login --username <username> --password <password>

**Пример:**
`login --username alice --password password123`

**Ошибки:**
- Пользователь не найден.
- Неверный пароль.

### 3. show-portfolio

**Назначение:** отображение валютных кошельков пользователя, их балансов и общей стоимости портфеля.

**Синтаксис:**
show-portfolio --base <currency>

**Пример:**
`show-portfolio --base USD`

**Ошибки:**
- Пользователь не авторизован.
- Неизвестная базовая валюта.
- Не удалось получить курс для пересчёта стоимости портфеля.

### 4. buy

**Назначение:** покупка указанного количества валюты. При отсутствии кошелька для выбранной валюты он создаётся автоматически.

В учебной модели покупка увеличивает баланс приобретаемой валюты без списания средств с USD-кошелька.

**Синтаксис:**
buy --currency <currency> --amount <amount>

**Пример:**
`buy --currency BTC --amount 0.05`

**Ошибки:**
- Пользователь не авторизован.
- Неизвестная валюта (`CurrencyNotFoundError`).
- Количество должно быть положительным числом.
- Не удалось получить курс валюты.

### 5. sell

**Назначение:** продажа указанного количества валюты.

В учебной модели продажа уменьшает баланс выбранной валюты без зачисления выручки на USD-кошелёк.

**Синтаксис:**
sell --currency <currency> --amount <amount>

**Пример:**
`sell --currency BTC --amount 0.02`

**Ошибки:**
- Пользователь не авторизован.
- Неизвестная валюта (`CurrencyNotFoundError`).
- Кошелёк для указанной валюты отсутствует.
- Количество должно быть положительным числом.
- Недостаточно средств (`InsufficientFundsError`).

Пример сообщения:

`Недостаточно средств: доступно 0.0500 BTC, требуется 0.1000 BTC`

### 6. get-rate

**Назначение:** получение актуального курса одной валюты относительно другой.

Если курс в `rates.json` свежий (менее пяти минут), используется кеш. Если курс устарел или отсутствует, приложение пытается получить новое значение через Parser Service или его заглушку.

**Синтаксис:**
get-rate --from <currency> --to <currency>

**Пример:**
`get-rate --from USD --to BTC`

**Пример результата:**

```text
Курс USD→BTC: 0.00001685 (обновлено: 2026-10-15 14:20:00)
Обратный курс BTC→USD: 59337.21
```

**Ошибки:**
- Неизвестная валюта (`CurrencyNotFoundError`). Приложение показывает поддерживаемые коды: USD, EUR, RUB, BTC, ETH.
- Некорректные аргументы команды. Приложение показывает правильный синтаксис.
- Не удалось получить актуальный курс (`ApiRequestError`).

Пример сообщения:

`Ошибка при обращении к внешнему API: курс BTC→EUR недоступен`

При ошибке внешнего сервиса пользователю предлагается проверить подключение к сети или повторить попытку позже.
