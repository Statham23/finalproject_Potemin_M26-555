# ValutaTrade Hub

Консольное приложение на Python для симуляции торговли
фиатными валютами и криптовалютами.

## Возможности

Проект предусматривает:
- Регистрацию пользователей.
- Управление виртуальными кошельками.
- Покупку и продажу валют.
- Просмотр истории транзакций.
- Получение актуальных валютных курсов.

## Технологии

- Python 3.12
- uv
- Ruff
- PrettyTable
- JSON
- Git

## Установка

Клонируйте репозиторий и перейдите в папку проекта.

Установите зависимости:

```bash
uv sync
```

## Запуск

```bash
uv run valutatrade
```

Или:

```bash
uv run python main.py
```

## Модель торговли

В проекте используется упрощённая модель симуляции торговли валютами.

- При покупке (`buy`) баланс выбранной валюты увеличивается без списания средств с USD-кошелька.
- При продаже (`sell`) баланс выбранной валюты уменьшается, а оценочная выручка рассчитывается в USD без фактического зачисления средств.
- Начальный виртуальный баланс пользователям не начисляется.
- USD используется как базовая валюта для расчёта стоимости портфеля.
- Для расчётов используются валютные курсы, полученные из внешнего источника, либо фиксированные тестовые значения.
