# ValutaTrade Hub

**ValutaTrade Hub** — консольное приложение на Python для симуляции торговли фиатными валютами и криптовалютами.

Приложение позволяет регистрировать пользователей, управлять виртуальными валютными кошельками, выполнять операции покупки и продажи, получать курсы из внешних API и оценивать стоимость портфеля.

Все пользовательские данные, портфели и валютные курсы хранятся локально в JSON-файлах.

## Возможности

- Регистрация и авторизация пользователей с хешированием паролей SHA-256 и индивидуальной солью.
- Создание и управление виртуальными валютными кошельками.
- Покупка и продажа валют в рамках учебной модели.
- Просмотр портфеля и его стоимости в выбранной базовой валюте.
- Получение курсов криптовалют через CoinGecko.
- Получение курсов фиатных валют через ExchangeRate-API.
- Ручное обновление курсов с помощью команды `update-rates`.
- Просмотр сохранённых курсов через `show-rates`.
- Кеширование валютных курсов с проверкой времени актуальности (TTL).
- Сохранение истории обновлений валютных курсов.
- Логирование торговых операций и работы Parser Service.
- Обработка ошибок с помощью пользовательских исключений.

## Установка

### 1. Клонирование репозитория

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd finalproject_Potemin_M26-555
```

### 2. Установка зависимостей

Для работы необходим установленный Python 3.12 и менеджер пакетов uv.

```bash
uv sync
```

Команда создаст виртуальное окружение и установит зависимости из `pyproject.toml` и `uv.lock`.

### 3. Настройка API-ключа

Для получения фиатных курсов используется ExchangeRate-API.

Создайте файл `.env` в корне проекта:

```dotenv
EXCHANGERATE_API_KEY=your_api_key_here
```

Получить ключ можно на сайте https://www.exchangerate-api.com/.

Для получения криптовалютных курсов используется публичный endpoint CoinGecko. В текущей реализации отдельный ключ для него не требуется.

**Важно:** файл `.env` добавлен в `.gitignore` и не должен отправляться в Git-репозиторий.

Без ключа ExchangeRate-API обновление фиатных курсов не сработает, однако криптовалютные курсы могут обновляться независимо.

## Поддерживаемые валюты

**Фиатные:** USD, EUR, GBP, RUB.

**Криптовалюты:** BTC, ETH, SOL.

USD используется как базовая валюта при хранении курсов. Для вывода портфеля и таблицы курсов можно выбрать другую поддерживаемую валюту, если необходимые курсы есть в кеше.

## Команды CLI

Команды вводятся в интерактивном интерфейсе после запуска приложения.

### 1. register — регистрация пользователя

```text
register --username alice --password password123
```

Создаёт нового пользователя и пустой валютный портфель.

Имя пользователя должно быть непустым, пароль — содержать минимум четыре символа. Пароль не сохраняется в открытом виде: для хранения используется SHA-256 с индивидуальной солью.

При повторной регистрации занятого имени приложение сообщает об ошибке.

### 2. login — авторизация

```text
login --username alice --password password123
```

Выполняет вход зарегистрированного пользователя.

При неверных учётных данных выводится сообщение об ошибке.

### 3. whoami — текущий пользователь

```text
whoami
```

Показывает имя авторизованного пользователя или сообщает, что сначала требуется выполнить `login`.

### 4. show-portfolio — просмотр портфеля

```text
show-portfolio
show-portfolio --base EUR
```

Выводит таблицу валютных кошельков, текущие балансы, оценочную стоимость каждой валюты и общую стоимость портфеля.

По умолчанию стоимость рассчитывается в USD. Параметр `--base` позволяет указать другую базовую валюту.

Для расчёта стоимости непустого портфеля необходимые валютные курсы должны присутствовать в локальном кеше.

### 5. buy — покупка валюты

```text
buy --currency BTC --amount 0.05
```

Увеличивает баланс указанной валюты. Если соответствующего кошелька ещё нет, он создаётся автоматически.

После операции приложение показывает предыдущий и новый балансы, использованный курс и оценочную стоимость покупки в USD.

Возможные ошибки: пользователь не авторизован, неизвестная валюта, некорректное количество или отсутствующий курс.

### 6. sell — продажа валюты

```text
sell --currency BTC --amount 0.02
```

Уменьшает баланс выбранной валюты на указанное количество.

Приложение проверяет существование кошелька и достаточность средств, после чего выводит новый баланс и оценочную выручку в USD.

При попытке продать больше валюты, чем имеется в кошельке, выводится ошибка недостаточного баланса.

### 7. get-rate — получение валютного курса

```text
get-rate --from EUR --to USD
get-rate --from USD --to BTC
```

Возвращает прямой и обратный курсы валют из локального кеша.

Например, при сохранённом курсе `EUR_USD = 1.12`:

```text
Курс EUR→USD: 1.12 (обновлено: 2026-10-18 14:40:48 UTC)
Обратный курс USD→EUR: 0.89285714
```

Перед выводом программа проверяет актуальность курса по TTL. Если он отсутствует или устарел, пользователь получает предложение выполнить `update-rates`.

**Команда `get-rate` не делает HTTP-запрос автоматически.** Обновление выполняется отдельной командой.

### 8. update-rates — обновление курсов

```text
update-rates
update-rates --source coingecko
update-rates --source exchangerate
```

Без аргументов программа обращается к обоим источникам.

- `coingecko` — обновление криптовалют BTC, ETH и SOL.
- `exchangerate` — обновление фиатных валют EUR, GBP и RUB.
- Без `--source` — обновление обоих наборов курсов.

Parser Service запрашивает данные, проверяет значения, добавляет записи в историю и обновляет кеш.

Если один API недоступен, другой продолжает обрабатываться. Информация об ошибках сохраняется в журнале.

Команда выводит количество обработанных курсов, число обновлённых записей кеша и время обновления.

### 9. show-rates — просмотр сохранённых курсов

```text
show-rates
show-rates --currency BTC
show-rates --top 3
show-rates --base EUR
show-rates --currency BTC --base EUR
```

Выводит курсы из локального кеша в таблице PrettyTable.

- `--currency` — показывает выбранную валюту.
- `--top N` — показывает до N криптовалют с наибольшим курсом относительно базовой валюты.
- `--base` — задаёт базовую валюту отображения.

Параметры `--currency` и `--top` одновременно использовать нельзя.

### 10. exit — завершение программы

```text
exit
```

Завершает интерактивную сессию.

## Учебная модель торговли

В проекте используется упрощённая модель симуляции.

- При `buy` количество выбранной валюты увеличивается без списания средств с USD-кошелька.
- При `sell` количество выбранной валюты уменьшается без зачисления выручки на USD-кошелёк.
- Первоначальный виртуальный баланс не начисляется.
- Покупка автоматически создаёт кошелёк, если он отсутствует.
- Продажа запрещена при недостаточном количестве валюты.
- Оценочная стоимость покупки и выручка от продажи рассчитываются по сохранённому курсу к USD.

Таким образом, приложение моделирует изменение валютных балансов и их оценочной стоимости, а не полноценную биржевую систему расчётов.

## Parser Service, кеш и TTL

Parser Service состоит из API-клиентов, компонента обновления курсов и JSON-хранилища.

**Источники:**

- CoinGecko — курсы BTC, ETH и SOL.
- ExchangeRate-API — курсы фиатных валют.

Все полученные значения нормализуются к формату `ВАЛЮТА_USD`. Например: `BTC_USD`, `EUR_USD`, `GBP_USD`.

### Кеш rates.json

Файл `data/rates.json` хранит последние сохранённые курсы:

```json
{
  "pairs": {
    "BTC_USD": {
      "rate": 80000.0,
      "updated_at": "2026-10-18T14:40:00Z",
      "source": "CoinGecko"
    }
  },
  "last_refresh": "2026-10-18T14:40:00Z"
}
```

**TTL (Time To Live)** — допустимый срок актуальности курса.

По умолчанию TTL составляет **300 секунд (5 минут)** и задаётся параметром `rates_ttl_seconds` в `pyproject.toml`, в разделе `[tool.valutatrade]`.

Команда `get-rate` использует курс, если он ещё актуален. При превышении TTL или отсутствии курса она предлагает выполнить `update-rates`.

Команды оценки портфеля и учебной торговли используют значения из сохранённого кеша; отдельной проверки TTL в этих операциях нет.

### История exchange_rates.json

Файл `data/exchange_rates.json` хранит записи полученных курсов, включая валютную пару, значение курса, время получения, источник и служебные метаданные.

История позволяет сохранять предыдущие значения при последующих обновлениях. Повторные записи с одинаковым идентификатором не добавляются.

### Надёжность хранения

JSON-файлы записываются через временный файл с последующей атомарной заменой (`os.replace()`), чтобы уменьшить риск повреждения данных при ошибке записи.

## Логирование и ошибки

Журналы создаются в директории `logs/`:

- `logs/actions.log` — результаты операций покупки и продажи.
- `logs/parser.log` — получение и обновление валютных курсов, включая подробности ошибок.

Для журналов настроена ротация файлов через `RotatingFileHandler`.

Основные пользовательские исключения:

- `CurrencyNotFoundError` — неизвестная валюта.
- `InsufficientFundsError` — недостаточно средств.
- `ApiRequestError` — ошибка получения или обновления курсов.

CLI перехватывает ожидаемые ошибки и показывает понятные сообщения пользователю.

Файлы `.env` и журналы `logs/` не включаются в Git-репозиторий.
